# 项目导航

第一次看项目，只需要先记住：`app/` 是应用本身，`docs/` 是说明。平时从根目录 `README.md` 开始；要改程序，再进入 `app/src/main/`。

## 先看这几份

- [README](../README.md)：项目是什么、如何安装和开发。
- [使用与升级](使用与升级.md)：功能用法、数据保存和升级注意事项。
- [当前计划](当前计划.md)：项目目标、最近两个阶段和待验收项目。
- [历史阶段](历史阶段.md)：E14 及更早的完成记录，查旧版本行为时再看。
- [养宠系统与小游戏优化计划](养宠系统与小游戏优化计划.md)：开源项目对比、养宠系统设计与分期实施。
- [界面设计记录](../DESIGN.md)：当前原生主题、共享家园与日程的设计令牌、组件规则及设备复核范围；扩展数据见 [design.json](../.impeccable/design.json)。

旧的专题计划和重复的项目说明已合并进“当前计划”“历史阶段”和“使用与升级”。`docs/界面草图/` 只放 0.39.0 旧界面的图片，作为视觉参考；它不是当前软件界面的准确截图。

## 文件夹地图

| 文件夹 | 用途 | 平时怎么处理 |
| --- | --- | --- |
| `app/` | Android 应用源码、资源和测试。`src/main/` 是软件，`src/test/` 是电脑上的单元测试，`src/androidTest/` 是设备测试。 | 开发主要看这里 |
| `game/home/` | 内嵌 Godot 家园场景、图集、作物资源与独立检查。经营存档仍在 Android 共享数据库。 | 场景制作和美术来源看这里 |
| `docs/` | 上面列出的项目说明、旧界面参考图和 `参考资料/` 里的象棋规则 PDF。 | 看说明时打开 |
| `.agents/skills/` | 从 GitHub 下载的七个设计 Skill，仅供开发时使用；来源见其中的 `README.md`。 | 平时不用打开，不打包进 APK |
| `ci/` | 构建入口和许可、交付、数据迁移检查脚本。 | 平时不用打开 |
| `third_party/` | 固定版本的 QuickJS 源码及第三方许可证文本。 | 不要随意删除或替换 |
| `gradle/` | Gradle Wrapper 配置，供项目统一构建工具版本。 | 平时不用改 |
| `evidence/` | 按阶段保存的验收、构建和测试结果；部分交付脚本会读取固定文件。 | 记录很多，平时可忽略；不要合并或删除 |
| `output/` | 当前 APK 和安装说明；`archive/` 存历史源码包、交付清单和升级基线。 | 安装使用当前 APK |
| `build/` | Gradle 构建输出，随时可重建或整个删除。 | 无需保留 |
| `.venv/`、`.local/` | 本机 Python 环境和 Gradle 下载缓存，已从 Git 忽略。开发脚本会使用它们。 | 不属于源码；不要为了整理仓库而删掉 |
| `.git/` | 版本历史。 | 不要手动改动或删除 |
