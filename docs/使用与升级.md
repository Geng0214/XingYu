## 日程与记录

日程页按当前角色空间保存安排。手机首屏显示一周日期，点击日期查看当天时间线；“展开月历”查看整月，横屏和平板将月历与安排并排显示。日期下的小点表示当天有记录，“今天”返回当前日期，“全部”可查看该分类所有记录。日历按设备时区显示，编辑保留记录原来的时区；跨天日程会出现在实际覆盖的日期中。

待办默认按“已逾期 / 今天 / 之后 / 已完成”分组，勾选后仍可取消完成；“回到日历”查看指定日期的待办。纪念日按每年发生日期显示，2月29日在非闰年按2月28日处理，首次日期之前不重复。

右下角加号添加当前分类的记录；点击安排查看详情，行末菜单可编辑或删除。日期和时间使用原生选择器，标题、备注、结束时间、提醒和逐条分享仍可编辑。顶部“分享与提醒”可查看实际聊天分享预览和本机提醒说明。经期页面只保存填写的记录，不预测周期。

四类记录都默认仅自己可见。逐条开启分享后，近期且在预算内的记录才会进入之后的新请求；原味模式全部排除。

## 共享经营家园与穿搭

未发布的分角色家园方案已清理；本次继续保留当前共享家园、聊天和其他个人记录。家园主画面是一张可走动的像素农场，游戏操作全部在地图内部打开；小屋、背包、制作、换装、布置、活动及更名使用地图内的图片入口。镜头会让出面板占用的位置，关闭面板后继续走动。打开背包或菜单时，未回应的居民邀约暂时隐藏，关闭面板后再次显示。

从家园导航直接进入同一个世界。首次自动建立“我”和聊天伙伴两个人物；已有角色成为居民，没有角色时建立“小伴”。新增或复制角色会在家园创建人物；删除角色让对应居民离开，田地、家具与共享背包保留。

- 点地面走动，靠近菜地、树木、池塘、工作台或人物后交互。左下方向键也可移动，全图按钮查看地图；走到房门进入室内。
- 六块菜地可以播种、浇水和收获。树木、石头和浆果丛可采集，池塘可钓鱼；采集和钓鱼消耗精力，休息恢复精力。
- 厨房和工作台可制作食物、布料与衣服。背包可出售农产品、材料、食物与服装，获取家园币；购买新家具同时消耗家园币、木材 3 和石头 1，已拥有的家具免费切换。
- 点击人物可聊天、赠礼、同行，或邀请喝茶、共读、吃饭、收拾、散步、休息。礼物、衣服、好感与对白分别保存在对应居民身上；共同活动记录实际参与者。
- 居民读取角色资料中已保存的性格与兴趣关键词，自主选择散步地点、步速和主动招呼间隔；例如爱读书的居民更常在书柜附近停留，外向居民更常接近玩家。短句邀约保留至回应、关闭或场景结束；点图片“回应”开始该居民所邀的活动，吃饭则选择食物图片。编辑人设后重新进入家园即可使用新的倾向。
- 背包、种子和配方用物品图格表示，点图格选择；材料图片旁显示持有／需要数量，换装显示当前人物。地图菜单提供更名、心愿、回忆及玩法入口，大字号图格改为两列并可滚动。
- 活动持续 20～30 秒，结束后领取家园币与经验；休息恢复 6 点精力，最多 12 点，每 100 经验升一级。今日心愿每天北京时间 00:00 更新，完成后可领取奖励。首次赠送 120 家园币、四件家具和六枚种子。

家园对白与性格行为是本机规则，不调用模型。人物寻路避开其他人物；两个人同时走动时会保留各自起终格，途中遇到占位便停下，原存档同格的居民会移到附近可达空格。居民的自主走动不会花费材料、经营田地或领取奖励；正在操作面板、同行和共同活动时暂停新的自主决定，应用进入后台暂停场景行为。位置、同行、田地、库存、家具和活动保存在同一份加密世界存档中，不随聊天角色切换。

新家园内部格式为 3，数据库 schema34，个人备份 v32。恢复预览明确选择导入备份世界，或只追加角色和聊天、让新角色入住当前家园。本机已有世界时不能再次导入另一个世界；追加模式不会导入备份里的家园物品与进度。v1～v31 的其他个人数据继续读取，未发布的旧分家园数据不再导入。

新建约会、城市漫游或隐秘之约会保存当时用户和活动角色的穿搭，之后换装不改变已有活动。灯塔主线与围巾支线的纪念物通过来源核对后进入共享背包，每局每种只领取一次，领取记录随家园备份保存。

聊天加号 → 共同活动 → 约会与小游戏。先完成自己的行动，再查看服务地址及模型，确认一次邀请。停止或返回会保留已确认进度；恢复后可重新邀请，不自动再次请求。摘要先预览再加入聊天草稿。功能分类见[项目导航](README.md)。

城市漫游支持自由选择地点和重访，隐秘之约按幕推进。新建时可编辑称呼、约定和 2～12 个场景，创建不调用模型；每幕完成一轮交流后才能进入下一幕。可查看全部剧情并搜索地点/对白；每次邀请仍需确认。离开有未保存内容时按提示选择继续编辑或放弃。

## 像素冒险

在“约会与小游戏”的新活动中选择“一起去像素冒险”，设置名称与双方称呼。方向按钮每次走一格，靠近物件后拾取或交互；在村庄修桥、林地制作提灯、旧塔寻找灯芯，再返回点亮灯塔。可切换近景、已探索全图和完整文字地图，背包与同行记录随独立活动保存。

移动与物品交互不调用模型。“写入这句对白”后另行确认模型与服务地址，角色只回复对白，不能移动或发奖。取消或中断保留已确认进度；恢复后可重新邀请，也可明确选择“暂不等回复，继续探索”。点亮灯塔后可继续支线，或确认结束。当前 v32 备份保存冒险与共享家园领取记录，旧版 App 无法读取新格式。冒险原开发证据保留于 `../evidence/E6_ADVENTURE/`，共享家园验收见 `../evidence/E11_SHARED_HOME/`。

未提交的对白与新建设置只保留在内存中：应用仍解锁时可跨屏幕旋转保留，锁定或进程结束会清除。已写入的进度从加密存档恢复。达到本局动作、记录或对白容量后，页面说明限制并关闭不能执行的操作，不自动删改历史。

## 象棋

在“约会与小游戏”选择“下一局象棋”，填写局名并选择执红或执黑。红方先行；执黑时棋盘翻转，坐标仍以红方底线为 0、黑方底线为 9。点选棋子和合法落点后确认，也可使用大按钮。红方棋子双圈、黑方单圈，完整文字棋局可查看双方全部棋子及坐标。角色回合需确认模型与服务地址；失败、停止或中断不会替角色落子，重新邀请创建新请求。

可查看棋谱、暂停/恢复和确认认输。规则由本机校验，包括将军、将死、困毙及重复局面的应用裁定；本版不是赛事裁判工具。阶段验收记录见[项目导航](README.md)中的 `evidence/` 目录。

## 猜词与四色卡牌

在“约会与小游戏”新建活动时选择“一起猜词”或“玩四色卡牌”。猜词可选谁来描述，你出题时可自定义分类、答案和别名；同义词只按填写的别名判定，最多八次猜测，放弃前会确认。角色猜词时不会收到答案；你猜词时，未确认的模型原文到终局才可查看。

四色卡牌可选先手，点击手牌再确认出牌，万能牌需选颜色。摸到可出的牌时可出刚摸到的牌或保留并结束回合。每次邀请角色均需确认模型与服务地址，不会自动连续请求。对局中只显示自己的手牌、双方张数和公共出牌记录；角色的附带文字可能提及手牌，因此终局前隐藏。功能边界与阶段记录见[项目导航](README.md)。

## 既有音频功能

点击聊天麦克风后，先选择本次录音的输入和输出；AI 回复的朗读只选择输出，不开启麦克风。连续语音也先选择本次设备，等待系统确认后开始。设备断开、焦点丢失或锁定会结束本轮，重新连接不会自动重开录音或朗读。设备名称和本次选择不写入角色或备份。

共同音乐和视频使用系统媒体输出，输出变化会停止，需要再次点击。Android 8 的本机音乐/视频已增加实际音轨与解码路径，旧设备的格式、蓝牙及音画效果待实测。B 站播放要求系统 WebView 支持所需静音和消息能力，不支持时会提示更新 Android System WebView；页面音频在应用内转为原生播放，异常停止，不绕过平台权限或解除静音继续。

上一补丁 0.27.1 修正连续语音的请求归属与结束竞态：只朗读本轮已经保存的回复，旧轮次完全停止后才能再次录音，音频实际播放完成后才开始下一轮。音频焦点丢失会暂停，返回聊天以外页面会结束。原版 0.27.0 的交付记录仍保留，本补丁记录在 `../evidence/E5B_FIX/`。

## 多角色群聊

聊天页右上角加号 → 创建多人群聊。填写群名和你的群内称呼，选择 2～8 位角色及各自模型连接，确认共享本群历史的说明。进入群后在输入框上方选择本轮发言者，再发送文字；可先点“查看发送内容”核对上下文。每次只由选中的角色回复，私聊和群聊同时只能生成一条答案。

群聊选项可管理成员/模型或删除本群。成员能看到加入前的本群已完成消息，但不会自动获取私聊、面具、私人记忆、世界书或工具权限。移除成员保留过去发言；删除群会删除该群消息，角色和私聊保留。失败/停止保留部分答案；重试生成新请求。草稿与未保存群设置只在内存中保留，锁定即清除；群聊目前为文本互动，未提供群媒体/群工具/群记忆。

## B 站共同观看

聊天加号 → 共同活动 → 一起看 B 站，填写观看名称和完整视频链接或 BV/av 号。先在本机保存，打开前核对第三方访问说明，确认后连接官方访客播放器。支持实际播放、暂停、全屏和进度记录；停止后可写感想并预览加入草稿。当前不接收短链接，也不绕过登录、付费或平台限制。B 站及其 CDN 会接收视频身份、起播时间和网络地址，App 不提供人设、聊天或 Key。系统网页组件关闭 Cookie、DOM 存储和网页缓存，但不承诺浏览器零残留。

## 本机共同观看

聊天加号 → 共同活动 → 一起看视频，使用系统文件选择器添加本机视频，确认后创建观看记录。支持当前设备可解码、可随机读取的视频文件，最多 512 MiB、6 小时。播放真实画面，暂停后可调整进度、写感想并预览放入聊天草稿。视频不发送给模型；每次播放先校验完整文件，较大文件需要等待。加入本机媒体库的视频会保留该文件的读取授权以供之后播放；移除媒体库项目或删除角色后清理不再使用的授权。退出页面、锁定或失去焦点会暂停。恢复备份后需重新选择同一份原文件。B 站来源使用上面的独立入口。功能边界见[项目导航](README.md)。

## 本机共同听歌

从“聊天加号 → 共同活动 → 一起听歌”进入曲库，通过系统文件选择器添加音频，预览后确认。支持平台可解码的 MP3、M4A、OGG、FLAC 和 WAV，文件最多 32 MiB、6 小时，每角色音视频合计最多 64 个文件。应用只保留你添加到曲库的单个文件读取授权，移除曲目或删除角色后会清理不再使用的授权；原文件留在原位置，移动或删除后需要重新关联，每次播放校验内容哈希。退出页面、锁定或音频焦点丢失会暂停。暂停后可拖动进度、写感想，再预览加入聊天草稿；音频本身不发送给模型。

曲目与听歌记录随加密备份保存，原音频与 Android 读取授权不在备份中。换设备或追加恢复后，点击“重新选择原文件”，选择同一份内容即可恢复播放。公开角色模板不包含曲目或听歌记录。

## 保留已有数据并升级

此前已接入“聊天加号 → 共同活动 → 一起读书”。选择或导入书籍后，每次活动独立保存进度与感想，支持暂停、继续、结束、所选页引用和摘要预览。摘要确认后加入聊天草稿，仍需点击发送。删除会话会删除关联活动；删除活动保留原书。活动随个人加密备份保存和恢复，公开角色模板不包含活动。

当前版本使用数据库 schema34、个人备份 v32，并能读取 v1～v31 的其他个人数据。升级请覆盖安装并保留应用数据；不要卸载或清空应用。升级会把同一角色的旧私聊合并为一个会话，保留消息、图片、资料、活动和关联记录；旧备份追加恢复也会合并该角色的多个私聊。未发布的旧分角色家园不转换，首次打开建立共享世界；其他功能继续保留。升级同时删除旧价格、用量及账单记录，新备份不保存这些数据。API 费用和用量请在服务商后台查看。MuMu 覆盖安装及 SQLCipher 迁移检查已通过，真机升级未验收。

若无法打开加密存储，请保留原应用及数据，不要清空、卸载或降级。个人备份只能在加密库可打开时生成，不能修复丢失的系统密钥。

## 模型连接与 DeepSeek

在“设置 → 模型连接”的“本地模型渠道”中编辑现有渠道或点“新增渠道”，填写渠道名称、服务地址与 API Key。宽屏并排显示名称、服务商、地址与 Key，手机和大字号纵向显示。DeepSeek 提供 Flash 和 Pro 选择项：Flash 使用 `deepseek-flash`，Pro 使用 `deepseek-v4-pro`；选择后点底部“保存渠道”，确认地址后生效。当前 Flash 的服务端名称为 DeepSeek-V4.1-Flash，模型 ID 不等于界面展示名称。旧配置中的 `deepseek-chat` 或 `deepseek-reasoner` 会提示重新选择，不会自动改为另一模型。

“模型列表”的“拉取当前渠道”读取填写地址对应的 `/models` 接口，可按模型名称或 ID 搜索并选择，也可以直接编辑模型 ID。“拉取全部渠道”逐一读取已保存渠道；正在编辑的已保存渠道使用当前填写的地址与 Key。返回的列表按渠道分组，点击模型后进入其所属渠道并选中该 ID；失败渠道逐项说明原因。读取结果仅保留在当前编辑页，修改地址、Key 或切换渠道后清理，重新进入需要再拉取。

模型列表读取不发送聊天内容；“测试连接”只在当前更改已保存时可用，会另行发送简短消息，可能产生费用。已保存 Key 不回显，地址不变且 Key 留空时，列表获取和保存可以使用原 Key；“显示 / 隐藏”仅作用于本次输入的新 Key。更换地址需填写该地址的 Key。连接偏好集中设置整段回复的总超时和图片输入；生图与语音区域打开各自的服务设置，返回后保留模型连接页未保存的更改。

删除渠道需确认。被角色、聊天、群聊成员或历史记录使用的渠道不能删除；提示后可以继续编辑。未使用渠道删除后清理其 Key，不删除角色和聊天记录。

模型名称以服务实际返回为准；官方接口说明见[DeepSeek 模型列表](https://api-docs.deepseek.com/zh-cn/api/list-models/)，本次于 2026-10-01 核对。第三方中转服务应填写其提供的地址、Key 和模型 ID。

## 开始聊天

1. “设置 → 模型连接”中添加 HTTPS 服务地址、模型及自己的 API Key。地址不支持嵌入账号口令、查询参数或片段；Key 单独加密保存在本机。确认目的地后再测试，测试会发送简短消息，可能产生少量费用。
2. 在“聊天”首页右上角加号选择“角色管理”，点“新增角色”创建，填写人设、开场白和默认模型；保存成功后回到列表。列表可按角色名称或人设搜索，每行的“编辑”修改资料，右侧菜单或长按提供删除角色和打开家园。开场白只在首次开始聊天时显示；人设与模型配置修改从下次请求生效。
3. “聊天”首页直接点击角色进入其唯一私聊；首次打开时选择模型连接。右上角加号也可创建群聊。连续短消息由模型按自然段输出，同一轮仍只有一个请求；聊天菜单可改为整段回复。停止会保留收到的内容。模型返回思考内容时显示“正在思考”，返回正文时显示“正在输入”；达到连接中设置的总超时会结束等待并显示可重试的错误。
4. 聊天页调色盘可以从本机选背景、预览并设置淡化与配色。聊天菜单或角色资料页相机按钮可以设置双方头像，图片只保存在该角色的本机空间，不发给模型。
5. 聊天首页每行右侧菜单或长按可编辑角色、删除角色；已开始的私聊还可置顶或删除对话。删除对话保留角色与家园；E11 删除角色会删除该角色的私聊、家园居民及关联个人记录，居民收到的礼物随之移除，共享田地、背包与家具保留；确认框会说明范围。群聊行同样支持编辑和删除，删除群聊保留角色、私聊与家园。首页搜索按角色名、群名或最近消息查找。长按消息气泡打开复制、转发、收藏、删除、多选、引用、翻译和朗读菜单；收藏连续短消息时按可见消息保存。
6. 聊天菜单“查找历史与收藏”在当前角色的私聊中搜索正文，支持中文和 emoji，点击结果定位原消息。搜索和收藏不额外调用模型。
7. 角色 JSON 模板支持先预览再导入或导出。只分享名称、人设和开场白；没有聊天、长期记忆、模型、凭据或图片。复制及重复导入创建独立空空间。
8. 角色资料或聊天菜单的“用户面具”可填写自己的称呼与用户设定，按角色独立保存。启用后从下一次发送或重试注入所选模型；预览显示当前草稿的系统提示词。角色复制和公开模板不含面具，个人备份包含它。

9. 角色资料或聊天菜单打开“世界书”，新建地点、背景和约定，选择常驻或关键词触发、优先级与会话范围。新条目默认关闭，保存前可选择启用；每个角色最多 64 条。
10. 世界书的“预览实际注入”选择会话并填写下一条消息，可检查选中条目和预算原因；这里只计算，不调用模型。模板可分享单条或全部，先检查完整 JSON，再用系统文件选择器保存；导入创建新身份、全部关闭，不带入原会话绑定。
11. 角色资料或聊天菜单打开“关系与原味模型”，可记录“谁 → 对谁”的关系、启停、优先级及会话范围。实际注入预览读取真实会话和设定但不调用模型；每个角色空间最多 32 条。
12. 切换“原味模型”后，从下一次发送或重试起不加入应用人设、开场白、用户面具、关系、长期记忆、世界书、短消息指令或工具。已有聊天历史仍会发送，服务商规则仍存在；要清空历史需在聊天首页删除该角色的对话，再点击角色重新开始。切回角色模式后保存的设定和工具授权继续使用。
13. 全新使用时按引导完成模型、角色、会话和第一条完整回复；离开引导处理步骤后，顶部入口可继续。设置中的“新手引导与帮助”可随时重开。
14. 发生错误时，提示可直达模型连接或帮助。脱敏诊断只包含固定状态字段，不含 Key、服务地址、模型名、正文、人设、路径或设备标识；预览后由你决定是否复制。
15. 要发送图片，先在“设置 → 模型连接”确认所选模型支持视觉并开启“图片输入”。进入使用该连接的聊天，点输入栏旁的加号选择单张 JPEG/PNG/WebP，可附文字或单独发送。应用会剥离原文件元数据并压缩，单张消息图片最多 1 MiB；当前图片和最近三张已完成历史图片会发往已确认地址。不同模型支持与计费以服务商为准。
16. 要发送文字资料，点输入栏旁的加号选择 TXT/Markdown 文件，或输入 HTTPS 链接。文件最大 256 KiB，链接响应最大 512 KiB，只接受 UTF-8 文本、Markdown 或 HTML；链接不携带凭据、不执行脚本、不跟随重定向。先检查来源、正文和截取提示，再点“加入待发送消息”。每条消息一份资料；当前资料和最近两份已完成历史资料会发送给当前模型。
17. 要发送 emoji 或表情，点输入栏旁的加号打开“表情与本机素材”。常用 emoji 会加入文字草稿；本机 JPEG/PNG/WebP/GIF 先预览并命名，再保存到当前角色独立的素材库。GIF 只保留首帧，素材会转为最大边 768、最多 384 KiB 的静态 JPEG。每条消息最多一个表情，可附文字，不能同时附普通图片或资料。模型始终收到你确认的表情名称；只有当前连接开启图片输入时才会收到像素。删除素材库条目不会删除已发送消息中的独立快照。
18. 要让 AI 发来一张图片，先在“设置 → 生图服务”保存独立 HTTPS 地址、模型、尺寸、超时、API Key。聊天加号选择“生成图片”，填写提示词并再次核对目的地、模型和尺寸。确认后一次只请求一张；卡片可停止，切换页面不改变归属。结果只接受接口返回的 Base64 图片，不下载 URL，也不会把文字回复当图片。
19. 要伴读长 TXT/Markdown，点聊天加号打开“TXT / Markdown 伴读”。每个角色有独立书架；文件最大 1 MiB、75 万字符，导入前显示章节和正文预览。阅读器保存章节与位置，每页最多 4,000 字；点“引用当前片段”后才进入聊天输入区。发送给模型的只有所选页，消息显示章节和字符范围，并可从消息菜单跳回原文。已被引用的文件不能删除，以免历史位置失效。
20. 要保存 AI 回复，点击状态为完成且有正文的 AI 消息，选择“保存为 TXT / Markdown”。检查完整预览、文件名、实际 MIME 与 UTF-8 字节数，再用系统选择器指定位置。应用直接写入返回的 URI，并在回读内容逐字节一致后提示成功；失败或权限丢失会明确报错，不会改写到其他目录。连续短消息保存该次回复的完整正文。
21. 要保存长期记忆，从角色资料页或聊天菜单打开“长期记忆”。每条记忆选择用户偏好、现实经历、当前计划或虚构剧情，可设置标题、正文、优先级和开关。实际记忆预览选择会话并填写下一条消息，显示真实选中、关闭、超预算或原味模式决策；预览不会调用模型。每次角色模式请求最多注入 4,000 字符，编辑或删除只影响之后的新请求和重试。
22. 要从对话提炼候选，点击一条已完成且有正文的 AI 消息，选择“提炼为记忆候选”。先核对唯一会发送的用户/AI 正文、模型和 HTTPS 地址；这会产生一次独立模型请求并可能收费。返回后逐条修改、勾选并确认，未确认内容不会保存。删除来源会话时必须选择断开来源或同时删除关联记忆。
23. 编辑记忆时可选择“按内容检索”或“始终带入”，并设置长期、7 天、30 天或 90 天。预览会用最近完成的对话与下一条消息在本机计算匹配百分比。发现同类型相似内容时必须选择并存或替换；替换的旧项进入“已暂时忘记”，可在长期记忆页恢复或永久删除。
24. 角色资料页打开“日记与心事簿”，可在“我的心事”和“角色日记”间切换。手工记录可直接编辑；AI 草稿需要先填写明确主题，核对模型、HTTPS 地址和完整主题，再发起独立请求。返回草稿仍需修改并点击保存。普通聊天不会自动读取日记，模型生成条目会保留来源说明。
25. 日记列表点“导出”会展示完整 Markdown、UTF-8 大小和文件名。确认后使用系统文件选择器保存，并在回读一致后提示成功；不会在公共目录生成缓存。
26. 角色资料页打开“时间与天气”，可分别开启“感知本机时间”和“感知已保存天气”。时间只使用发送瞬间的系统时钟和当前时区，不联网。天气关闭、缺失或超过六小时不会加入新请求；原味模式始终排除时间天气。
27. 设置天气时先填写城市并检查将发往 Open-Meteo 地点检索服务的完整文字。确认后从最多五个候选中选择，再检查城市、行政区、国家、时区、经纬度、天气服务和许可后获取天气。应用不申请定位权限、不按 IP 猜城市、不后台刷新；只会保存用户手工获取的最后快照。
28. 角色资料页打开“日程与记录”，可创建日程、待办和每年重复的纪念日，也可保存经期起止、流量和备注。四类记录都属于当前角色空间，默认不分享；只有逐条开启“在聊天中分享”后，近期且在预算内的记录才进入之后的新请求。原味模式始终排除，复制角色和公开角色模板不复制这些记录。
29. 日程、待办和纪念日可选一次提醒。Android 13 及以上只在选择提醒时请求通知权限；拒绝后仍保存记录，但不会显示通知。提醒使用不精确系统闹钟，可能因省电策略延迟；通知固定显示“有一条本机提醒”，不包含角色名、标题、备注或经期内容。应用不申请精确闹钟权限；强制停止后的系统行为和开机重排仍需真机确认。
30. “设置 → 主动消息”先开启本机总开关并设置全局每日上限，再到角色资料中的“主动消息”选择会话、模型、免打扰时段、最小间隔和角色每日上限。角色开关与总开关默认关闭；开启需要通知权限。系统每次调度至多为一个到期角色生成一条文本，不补发错过时段，不调用插件、图片、文件、生图或自动操作。锁屏通知固定显示“本地伴侣有新消息”“解锁应用查看”。
31. 先在“设置 → 语音服务”分别保存录音识别和文字转语音服务。单次麦克风按钮仍会在停止后显示识别目的地，文字只进入可编辑输入框；AI 回复菜单仍可单次朗读。
32. 当前聊天右上角电话按钮打开连续语音预览。选择并核对两个 HTTPS 目的地后开始；每轮说完点击“说完了”，AI 回复播放完会自动进入下一轮。识别、生成、合成和播放期间可“打断并说话”。返回、切换聊天、锁定或退到后台会结束，音频不保存；识别文字与回复作为普通加密消息保留。

收藏随原会话或角色删除，不是备份。每个角色可设置自己的“我”的头像，其他角色空间不会一起变化。应用已移除禁止截图和录屏的限制。

## 扩展

设置中可添加远程 MCP Streamable HTTP 服务，或导入 ToolPkg/安装内置时间示例。预览并安装后默认停用，需启用并为角色授权。编辑现有服务配置、刷新工具目录或停用服务都会撤销该服务的角色授权；启用并获取工具目录后，需重新选择角色与工具授权。每次调用前确认完整参数，停止聊天会取消工具。工具结果会送给当前模型，可能产生额外模型请求与费用。

本版 ToolPkg 为 schema 1/API 1.0.0 的纯计算子包，支持时间、文本、数字和 JSON；不支持任意旧 Operit 包、设备文件、网络宿主桥、UI Hook。插件归档、授权和调用记录在本机加密库内，不向公共目录解压。

## 个人备份

“设置 → 加密备份”先预览范围，再设置并重复输入 12～128 字符的独立口令，选择文件位置。默认不含 API Key；勾选后 Key 也在口令加密内容内，任何一个引用无法读取都会中止本次含 Key 备份。请另外保管口令，遗忘后无法找回。保存完成会回读验证；未完成的文件不能用于恢复。

恢复先选 .cbackup、输入口令、检查预览，再确认追加副本。原角色和聊天保留，重复恢复也会新增副本；恢复的角色/空间/会话/模型/生图配置/伴读原文/长期记忆/日记/日程/经期记录重新分配身份，历史、背景、头像、消息图片、消息资料、伴读章节与进度、表情素材、消息快照、时间天气设置、主动消息历史及已完成生图保留，伴读引用、记忆、日记、环境、日程、经期和主动请求归属同步改写到新身份。含 Key 时使用目标手机密钥重新加密并绑定原服务地址，不含 Key 时需重新填写。扩展、角色工具授权和所有角色的主动消息开关关闭，隐私锁和本机主动消息总开关不从备份导入；使用前请检查服务目的地并重新授权。

备份保存聊天、活动、家园及领取流水。恢复保留已确认进度并中断在途请求，为导入数据重新分配身份；不重新发物或自动调用模型。旧备份缺少的后续功能集合保持为空。音乐与视频恢复后需重新关联原文件，B 站需重新确认后才联网，不恢复播放状态。录音和合成音频不进入备份。最多 32 MiB 内容和 10 万条记录，不导出 Android Keystore 私钥、通知权限或本机主动消息总开关。只为未来且明确设置提醒的日程重新安排提醒；主动消息角色开关始终保持关闭。处理期间不要结束应用；系统文件选择器返回时可能需要先解锁。选择云盘意味着将加密文件保存至对应服务。数据范围见[项目导航](README.md)。

## 隐私锁

在“设置 → 隐私与数据”开启。Android 11 及以上使用系统生物识别或锁屏凭据，Android 8～10 使用系统锁屏确认。启用和关闭时都需要验证；离开应用、冷启动或手动锁定后需要重新解锁。锁定会停止生成与插件；已经收到的部分答案会保留，尚未保存的表单可能需要重填。文件选择结果会等到解锁后再处理。

当前实现进度见[当前计划](当前计划.md)，项目目录和阶段记录见[项目导航](README.md)。
