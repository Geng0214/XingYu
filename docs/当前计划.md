# 项目计划与当前进度

此页记录项目目标、当前进度和最近两个阶段。E14 及更早的完成记录见[历史阶段](历史阶段.md)；目录入口见[项目导航](README.md)，逐项结果见根目录 `../evidence/` 阶段记录。

## 项目目标

在保留 Operit 插件能力的基础上，逐步把本应用做成可个性化的陪伴小手机。当前产品方向由用户提供的功能参考和开源项目调研整理而来；它们是设计参考，不代表功能已实现或许可证允许复制代码与素材。

- 日常陪伴：私聊与群聊、角色设定、世界书、记忆、日记、关系、日程、纪念日和可控主动消息。
- 多媒体和共同活动：图片、文件、表情、生图、语音、共读、听歌、视频、剧情和小游戏；沿用现有功能记录，不复制同一份业务数据。
- 个性化空间：应用内陪伴桌面、共享家园、主题、角色与关系设置；个人记录按角色隔离，家园世界由用户和全部居民共同经营，桌面和主题预览后保存。
- 扩展与权限：继续维护 ToolPkg/MCP 扩展；服务和设备能力按角色或动作单独授权，执行前说明目标与请求，操作后可撤权并查看实际结果。
- 数据与帮助：加密备份、兼容升级、使用说明、可检索帮助和脱敏诊断；云服务保持可选，费用和数据发送范围在操作前说明。

不伪装系统 Launcher，不宣称模型有真实情绪，不把模拟结果说成真实交易或设备操作。主题文件不执行脚本，导入内容先预览；复用外部代码或素材前，逐项确认许可证和分发义务。

## 调研参考

以下项目仅供产品设计参考，不表示本项目已实现对应功能，也不直接复用代码或素材：

- 陪伴手机：[AI Virtual Phone](https://github.com/xiaolongbao0709/ai-virtual-phone)、[Whale 小手机](https://github.com/whale-Yd00/freeapp)、[猪猪机](https://github.com/lw0129-jj/PiggyPhone.JJ-STAR)、[叙事诗](https://github.com/Island-glitch/Poemnarapk)、[柚月小手机](https://github.com/gaigai315/yuzuki-phone)、[ZeroChat](https://github.com/sh1nny0u/ZeroChat)、[xiao-shouji](https://github.com/jiuyi777/xiao-shouji)：角色空间、收藏检索、日记、伴读、群聊和主动消息。
- 角色和扩展：[SillyTavern](https://github.com/SillyTavern/SillyTavern)、[RisuAI](https://github.com/kwaroran/RisuAI)、[LettuceAI](https://github.com/LettuceAI/app)：角色设定、世界书、群聊、长期记忆和插件管理。
- 设备能力：[OpenPocket](https://github.com/pockebot/openpocket)：设备隔离、计划任务和工具权限；真实设备操作需要明确授权。
- 桌面和主题：[Miya](https://github.com/lixooo00-lab/mingruis-miya)、[露露机](https://github.com/jiacimu-droid/lulu-phone)、[Mira](https://github.com/kernelx30/Mira)、[Lawnchair](https://github.com/LawnchairLauncher/lawnchair)、[Orbit Assistant](https://github.com/lpnovi/Orbit-Assistant)：可编辑桌面、主题预览、已有数据摘要、共同活动入口和可撤销权限。

- 家园经营：[心动小镇官方介绍](https://www.xd.com/games/single/14178%3Flang%3Dzh)的园艺、烹饪、建造与自由生活；[星露谷官方玩法](https://www.stardewvalley.net/about/)的农场、制作、钓鱼和居民关系；[饥荒联机版官方介绍](https://www.klei.com/games/dont-starve-together/)的共同世界、资源采集、种植与建造。此次借鉴地图内操作和经营循环，不复制游戏素材或代码。

项目许可证各不相同，特别是部分小手机项目限制复制和分发；如需借用代码或素材，应在实施时单独核对许可证。

## 已完成：E15 Godot 共享种地家园

按用户选定路线，改编 MIT 2D Farming Game 的图集／作物阶段代码，改为内嵌 Godot 场景。上游 Sprout Lands 美术有非商业限制，本轮改用 Kenney CC0 素材，不纳入该素材包。

1. 已接入 Godot 4.7.2 Android 库、唯一永久渲染门户及 PCK 导出任务。离开家园时隐藏并暂停，回到页面继续渲染；继续只有一个应用安装身份。
2. 已删除旧 Canvas 世界与人物，地图坐标、碰撞、共享存档、背包、制作、经营和居民性格规则继续使用 Kotlin / Room 事实来源。传入引擎的数据不包含人设正文、聊天内容或凭据；schema34／备份32／家园格式3均未改。
3. 已加入作物成长、人物朝向与步态起伏、池塘水波、操作粒子和场所标记；图像操作全部在地图内，原生控件保留字号和无障碍语义。系统移除动画关闭装饰动作；普通面板期间隐藏邀请，收起后恢复。
4. 570 项 JVM 测试、Godot 阶段／132图格／浮数池塘邻格检查通过。最终 Release 构建、包审计、v2 签名及16KB对齐通过。MuMu 已实测播种、浇水、自然成熟收获、CLEAN回应与领取、进屋、页面往返和重启保留；完成375dp手机、200%字号、1600×900横屏及1920×1200平板矩阵。最后Android偏好读取修正仅重建Release并实测实时系统设置，未重复JVM用例。
5. 已完成五项独立修复评分，均 resolved，专项 `ship`；第三方声明、构建说明和单版 APK 已更新。设备设置恢复原值，正式版继续保留原聊天和共享世界。具体步骤、截图与未验收范围见 [E15 验收](../evidence/E15_GODOT_HOME/validation.md)。
