# 日常聊天 0.4.0 验收

依据[项目计划与当前进度](../../docs/当前计划.md)，本次四项开发已完成：本机头像、会话置顶、消息收藏、角色内全文检索与原文定位。界面基于 0.3.0 即时聊天版，继续原生 Android 单工程，运行依赖不增加。

## 已执行

- 干净构建通过：build-final-clean.log，1 分 47 秒，141 项任务。该次之后补齐角色资料页头像入口、窄屏对话框滚动与设备升级断言，再执行 build-validation.log 验证最终修改。
- JVM 29 项保留并通过；包括 M1 网络分片/异常、M2 协调器隔离和模板、0.3 分段文本测试。
- library-sql.json：实际 schema 3→4 SQL 在宿主 SQLite 执行，结构与 Room v4 一致，旧消息、背景及凭据引用保留；240 条合成记录、50 次 A/B 交替，跨角色检索和变更零命中；分页 50/50/20，无重叠；中文、emoji、百分号、下划线和注入字符串按字面处理；收藏终态保护、关联删除及置顶排序通过。原 1→2 和 2→3 宿主检查再次通过。
- 升级在任何 ALTER 前检查旧关联，异常报错；不清库重建。头像单独小 BLOB 表，每图 128px、最大 64 KiB，不与背景 BLOB 合并为超大行。选择器在根页面注册，预览和保存冻结角色身份。
- Release Lint 0 错误，24 警告，主要为冻结依赖/版本目录、平台 ExifInterface、KTX、KAPT、ChromeOS ABI 和移除 Provider 标记提示。实际权限、组件与原生库由 apk-audit.json 检查。
- 最终增量验证 build-validation.log 通过，1 分 37 秒。签名证书与旧版一致，zipalign 16 KB 检查通过；运行依赖仍是 123 个坐标。

## 未执行的验收

本机没有连接 Android 设备。ChatLibraryAndroidTest、WallpaperAndroidTest、MigrationAndroidTest 等只编译，不能标记运行通过。需要设备验证覆盖升级 0.1/0.2/0.3→0.4、凭据解密、加密图片和正文落盘、系统选图回调、收藏恢复、搜索定位与切换页面竞态。

视觉验收还包括：小屏/横屏/大字体、键盘遮挡、读屏和触控、浅色/深色背景对比、点击气泡收藏与长按文本选择、停止时短消息尾段、旋转及进程结束恢复。当前没有真机截图，不把代码审查写成视觉验收。

M1 两个独立真实服务商、M2 第二台设备模板导入与三人观察继续待验。原始 M0/M1/M2/UI03 证据保留。结论仍为“开发完成、验收待补齐”，不能宣称全部阶段通过。最终源码提交、APK 哈希、体积与签名见 delivery.json。
