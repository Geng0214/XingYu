# 角色入口与陪伴首页验收

## 调整内容

- 聊天首页筛选行列出角色；点击角色会选中该角色的数据空间。右上角新增“管理角色”入口，角色编辑页的返回按钮回到聊天首页。
- 陪伴页聚焦今天安排、继续共读和共同回忆；不再重复展示角色选择、角色身份卡或最近对话。没有选中角色时，页面说明如何从聊天首页选择。
- 删除“常用入口”和“最近对话”桌面区块、对应布局编辑项及本地布局字段。陪伴桌面仅保留今天、阅读和共同回忆的布局设置。
- 更新陪伴页日程空状态，使用日期和面向用户的提示语。

## 构建与 MuMu 检查

- `./ci/build.ps1` 通过，583 项单元测试全部通过；失败、错误、跳过均为 0。
- Release APK 已生成并覆盖安装 MuMu；APK v2 签名验证通过，`zipalign -c -P 16 4` 检查通过。
- 打开聊天首页的角色管理，角色列表正常显示；返回后留在聊天首页。
- 选择角色筛选后，筛选状态更新；进入陪伴页能看到该角色空间的数据摘要。
- 陪伴页截图显示“今天的安排”、日期、日程空状态及家园摘要；页面不再显示角色身份卡、最近聊天或常用入口。
