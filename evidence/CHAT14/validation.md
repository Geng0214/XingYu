# 内置主题预览与图标样式验收

## 问题原因

内置主题卡片原先使用独立概念图片，因此预览与安装后的实际页面不一致。应用主题时配色、字体、圆角和图标外观本身都会保存；但“团子日常”设置为实心图标，与默认值相同，造成只改变颜色的观感。已移除三张旧概念图。

## 实施

- 主题卡片改用真实聊天标题、会话行、搜索/新建图标和底部导航组件绘制，实时使用对应主题的配色、字体、圆角与图标样式。
- 三套内置主题分别使用线框、实心和柔彩圆底图标。柔彩图标使用主题次级容器色圆底；主题编辑器也增加了该选项。
- 对仍启用旧版“团子日常”且保存实心图标值的安装，迁移为柔彩样式。迁移不修改已自定义并解除内置主题关联的配置。

## 验证

- `./ci/build.ps1` 成功；583 项单元测试通过，失败、错误、跳过均为 0；Release 构建成功。
- Release APK 的 v2 签名校验通过，`zipalign -c -P 16 4` 检查通过。
- APK 覆盖安装到 MuMu（`emulator-5554`）并成功启动。检查了主题卡片的实际组件预览，以及升级后应用中聊天、陪伴、日程、设置等图标的柔彩圆底；最新日志窗口未发现应用崩溃。
- 此轮未在 Android 真机上验收。
