# E1 第一段：MCP 传输与调度契约

日期：2026-09-20。状态：阶段开发与宿主单元测试完成，E1 总体验收未完成。

## 实现与验证

- 官方 MCP Kotlin SDK 0.10.0 + Ktor OkHttp 3.2.3，复用基线的客户端接入方式，保留现有 HTTPS 校验。
- 本机合成 HTTPS 服务验证初始化、会话头、工具列表、两页枚举、JSON/SSE 返回、工具调用、结果、关闭及取消；使用合成凭据和正文。
- 401/403、429、404、503 的错误仅暴露固定类别；重定向未访问跳转目标；超时与失败没有自动重放调用。
- 固定/分块响应上限、JSON 深度、SSE 元数据、重复游标、工具定义变化、无效参数与重复 JSON 键覆盖。工具返回 isError 会保留，不误当正常完成。
- ToolDispatcher 的内存存储契约验证用户拒绝、错误身份、重复 ID、8 次预算、撤权与迟到结果；50 次 A/B 交替和 20 轮取消/撤权组合通过。
- 原文本服务、角色模板、请求上下文、聊天协调与气泡测试回归通过；新增凭据无法解密和等待确认时取消测试。共 48 项单元测试，无失败或跳过。

执行命令：ci/build.ps1 -Tasks ':app:testDebugUnitTest',':app:writeRuntimeInventory','--offline'。关闭的本机代理不能下载依赖，本次使用唯一已有缓存；Kotlin reflection 明确约束为项目版本 2.2.21。

结果摘要见 [transport-tests.json](transport-tests.json)。本次客户端初始测试曾因测试证书不包含 127.0.0.1 而失败，修正证书 SAN 后通过；未关闭域名或证书验证。并发测试用 supervisorScope 独立观测预期失败，不让预期 ACCESS 异常取消整个测试父协程。

- 这 50 次调度交替没有进行原 M2 的每角色 10 标记实际数据库/请求上下文验收，不能替代该用例；原 M0/M1/M2/UI03/CHAT04 证据保留。
