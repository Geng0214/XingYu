# E12 地图内图像操作与居民自主生活验收

日期：2026-10-02。此轮迭代延续 E11 的共享世界，数据库 schema34 与个人备份 v32 不变。用户要求移除地图外游戏按钮、居民依照人设自主行走和主动找玩家互动、增加可点选图像。

## 实现范围

- 游戏目标面板、背包、配方、种植、换装、布置、心愿、回忆、更名、确认及活动领取均置于地图 Box 内；根导航继续提供聊天、家园、日程、设置。
- 原创 Canvas 像素物品、种子袋、工具、家具与人物预览组成交互图格，短标签、数量及进度保留。材料以图片及持有／需要数显示；200% 字号采用两列图格。
- 人设的性格与兴趣关键词影响目的地权重、步速及主动间隔。这是本机规则，不使用在线模型，也不自动消耗经营材料或领取奖励。
- 所有人物的寻路与每一步推进共享当前占位，走动同时保留起终格；旧同格居民分配至最近可达空格。遇到新增占位中止路径，下一次明确移动重新计算。
- 邀约保留至回应、关闭或场景结束，不被后来的邀约替换。回应使用邀请者与具体活动；吃饭选择该居民的食物图片。

## 检查与设备证据

执行入口 `ci/build.ps1`，任务为 `:app:testDebugUnitTest`、`:app:assembleDebug`、`:app:assembleRelease`。修正批次最终构建成功，564 项单元测试无失败／错误／跳过，其中 9 项覆盖性格、自主接近与人物占位，见 [测试汇总](unit-tests.json)。本轮没有重跑 Android SQLCipher 仪器测试；E11 的 11 项结果仅为历史证据。

MuMu Android 15 运行原生 Compose 页面，检查 375dp 手机、800×375dp 横屏、1067×600dp 宽屏及 200% 字号。对应截图位于 [原生截图](../../.impeccable/review/e12/)。`verify_home_controls.py` 读取实际 UI 层级，与地图 bounds 比较；对应的 `*-controls.json` 只证明控件边界，不证明触控和连续行为。

首轮已实际制作太阳帽、赠送给“初见”并换装；[制作结果](crafted-hat.png)与换装截图显示真实状态变化。界面操作曾改变 Debug 验收存档的田地和库存，不属于居民自主经营。

[自主连续序列](autonomy-observations.json)记录最终修正版约 48 秒、16 次原生屏幕捕获、0 次触控。人物处在分开的格子，玩家静止、居民主动接近发出邀约后继续自主走动；邀约持续保留。早先 45 秒 [原始录屏](autonomy.mp4) 来自修正前版本，未逐帧解码，不声明视频审查通过。

[实际回应记录](invitation-response.json)对应邀请／回应同时点 UI 层级及边界报告：点击一次“回应初见的邀约”，直接开始喝茶并显示 19s 进度，精力从 7 到 6；活动结束后手动领取，家园币从 85 到 97。[邀约](../../.impeccable/review/e12/invitation.png)和[进行中](../../.impeccable/review/e12/invitation-response.png)均为最终 Debug 包原生捕获。吃饭邀约未单独在设备上操作；对应居民食物选择由源码复查确认，不能视为独立设备验证。

界面层级观察工具在连续调用中两次退出码 139；独立 `adb shell uiautomator dump` 与原生截图继续可用。工具失败未作为应用验收通过，也没有因此添加应用替代逻辑。

## 复核与交付

独立完整审查认可地图内操作、图像化、性格行为、横屏和大字号；提出人物同格重叠及邀约时限／回应两项修正。单批修正后重截同组 12 张画面，新增实际回应截图，复查两项均为 resolved，disposition 为 `ship`。该结论只覆盖两项修正，未扩大为全产品验收；详见 [复核记录](../../.impeccable/review/e12/verdict.md)。

最终 Release 0.39.0／code40 已在 MuMu 覆盖安装。原有“你好”角色与最近消息可见内容逐项一致，家园名称、居民、120 币及 7 精力保留，见 [升级核对](release-upgrade.json)与安装前后截图／UI 层级。该核对范围为可见状态，不是完整数据库内容比对或备份导入测试。当前 Release PID 的 AndroidRuntime 错误记录为空；设备历史日志中的两次 Map 图标异常发生于 19:19～19:20 的早期 Debug，图标族映射已在后续构建补齐，不属于最终包。

[APK 包检查](apk-audit.json)、v2 签名、16KB zipalign 与三份原生 ELF PT_LOAD 对齐通过。交付文件 [local-companion-0.39.0.apk](../../output/local-companion-0.39.0.apk) 与最终构建一致，17,072,719 字节，SHA-256 为 `87E02A974086856FB0D3766CAB898261577F966234C019BED8FE95AC47AD1D5A`。

结束时已恢复 MuMu 物理 900×1600／240dpi、字号 1.0、自动旋转及日间系统模式。真机触控、性能、TalkBack、系统“移除动画”及在线模型本轮未验收，所有并发行走路径未穷尽测试。历史源码包与 `delivery.json` 未重新生成。
