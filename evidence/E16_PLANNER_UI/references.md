# 日程界面参考

2026-10-03，用户要求查找网上较好的日程管理界面，并优化现有 App。采用官方产品与帮助资料的交互结构，不复制第三方代码或图像。

| 官方参考 | 值得借鉴的部分 | 本轮采用 |
| --- | --- | --- |
| [Structured visual planning](https://structured.app/visual-planning)、[入门指南](https://help.structured.app/en/articles/380546) | 日期导航与每日时间线，日／周／月视图 | 手机周历与当天时间列，减少首屏说明文字 |
| [TickTick 功能介绍](https://ticktick.com/features?language=zh_cn) | 月／周／日程视图，列表管理和快速添加 | 可展开月历、全部记录入口、待办分组与单一加号入口 |

星语已有日程、待办、年度纪念日、经期记录和逐条分享。本轮继承 Material 3 全局主题，不增加这些参考产品中的云同步、拖动改期或自然语言输入功能。

官方网页资料读取成功；浏览器图像捕获未成功。因此本记录不把第三方界面截图列为已经验收的视觉证据。安装后截图仅来自 MuMu 中的星语 App。
