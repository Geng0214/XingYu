# E16 日程界面优化验收

2026-10-03，按用户要求研究日程产品并优化现有 Android 日程页。参考及采用范围见[官方资料](references.md)。这是界面迭代，数据库 schema34、个人备份 v32、正式包名及既有记录接口不变。

## 实现

- 手机周历／可展开月历与当天时间线；宽屏月历与安排并排显示。当天小点来自当前分类的真实记录，“全部”保持历史及未来记录可发现。
- 待办按逾期日期、今天、之后、已完成分组；完成可取消。纪念日显示年度发生日期并保留既有闰日规则。
- 时间、详情、备注与逐条分享继续使用原记录。顶部提供实际分享预览和提醒说明，主要界面移除大段技术说明。
- 编辑采用原生 Compose 日期选择与24小时制时间输入；主题及字号跟随应用，选择器返回后不改变主页面状态栏外观。
- 图标严格登记全部新增样式，未增加图标替代逻辑。存储记录先验证，再生成日历；非法记录显示读取错误，未隐藏为正常空白页面。

## 检查记录

1. 首次编译发现信息图标名称不存在，修正为已有 Material `Info`。
2. 全量 JVM 检查576项通过，其中6项为新增日历用例：月历周一对齐、跨年周、设备时区、午夜结束边界、夏令时、年度纪念日首次日期及闰年规则。
3. 初次 MuMu 打开日历发现 AutoMirrored 箭头未注册导致闪退，原因和堆栈见[原始记录](runtime-crash-before-fix.log)。已补齐普通及镜像图标样式，新增图标契约专项1项通过，覆盖六个新增图标的实心／线框／柔彩样式与镜像属性。全量检查发生在该修正前，专项检查发生在修正后，结果见[JVM摘要](jvm-summary.json)和[图标专项](icon-test.xml)。
4. 已在正式单应用身份实际创建 `E16_QA_Walk`（10:00）、`E16_QA_Task`（09:00）和 `E16_QA_Annual` 三条临时记录，分享默认关闭、提醒关闭。待办完成及取消完成、打开编辑并取消、经期编辑打开并取消均已操作。未写入经期记录。
5. 首轮设备矩阵发现旧平台选择器配色独立于应用，关闭后状态栏图标颜色异常；改用 Compose 选择器与明确校验的时间输入。200% 编辑器首次截图处于进入动画中，确认轮重新捕获已稳定的界面。
