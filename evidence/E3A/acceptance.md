## 已接入

聊天输入栏可选择单张 JPEG、PNG 或 WebP，并可附带文字或独立发送。入口只在当前模型连接显式开启图片输入后启用；旧连接迁移后保持关闭。保存连接时再次显示 HTTPS 目的地，并说明聊天、所选图片和 API Key 的发送范围。

输入图片限制 20 MiB 和 4000 万像素。应用校正 JPEG 方向后只重绘像素，以 JPEG 重新编码到最大边 1280、最多 1 MiB，不保留原文件名、URI、EXIF、GPS 或其他原文件元数据。图片与用户消息在同一个事务中写入 SQLCipher；读取、发送、重试和删除同时校验角色、空间、会话、消息与请求身份。每个会话最多 32 张，删除消息/会话/角色会级联删除附件。

模型请求使用 OpenAI 兼容的文字与 `image_url` 数据 URL 内容块，不发送本机路径。请求冻结当前图片字节和模型配置版本，并最多附带最近三张属于完整历史回合的图片；失败或取消轮次不进入后续上下文，重试复用原用户消息与原图。工具模型回合沿用同一多模态消息数组。不同服务的视觉模型、分辨率和计费差异由用户确认，服务端拒绝不会自动切换模型或目的地。

Room 提供显式 10→11 迁移：新增默认关闭的视觉开关及消息附件表，旧配置、角色、会话、正文、凭据引用和账单不变。个人备份升级为内容 v6/schema 11，包含视觉开关与消息图片，继续读取 v1～v5；恢复前检查附件归属、MIME、尺寸、字节上限和 SHA-256，并随消息身份一起重映射。
