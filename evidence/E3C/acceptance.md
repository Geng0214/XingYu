# E3 第三项：表情与本机素材开发记录

日期：2026-09-20。版本 0.15.0/code 15/schema 13。常用 emoji 与角色空间独立的静态表情素材库已完成开发并形成签名交付；系统文件选择器、设备 SQLCipher、覆盖安装、GIF 首帧和真实视觉服务尚未执行，因此状态为“E3 表情与本机素材开发完成、验收待补齐”。E3 后续生图、伴读与文件输出尚未完成，M1/M2/E1/E2 及 E3 前两项的原有待验项继续保留。

## 已接入

聊天输入栏的加号菜单新增“表情与本机素材”。常用 Unicode emoji 直接加入文字草稿；JPEG、PNG、WebP 或 GIF 通过 Android 系统文件选择器读取，预览并由用户确认名称后才保存到当前角色空间。应用不读取或保存原文件名与 URI，只保留重编码后的静态 JPEG 像素；最大边 768、最多 384 KiB，GIF 只保存首帧。

每个角色空间最多 64 个素材，支持收藏、取消收藏和删除。每条消息最多包含一个表情，可附文字，不能同时带普通图片或资料；每个会话最多 64 个表情消息。消息保存独立名称与像素快照，删除素材库条目后历史展示和重试仍可用。素材、消息、发送、重试、删除和备份同时校验角色、空间、会话、消息及请求归属。

模型始终收到用户确认的表情名称。当前连接明确开启视觉能力时才发送处理后的像素；普通消息图片和表情像素共用最近三条已完成历史视觉内容窗口。请求创建后冻结表情快照和模型配置，切换角色、删除素材或修改连接不会改变在途请求。本版不含动画播放、联网表情商店、外部版权素材下载或 meme 模板。

Room 提供显式 12→13 迁移，迁移前检查旧消息、图片附件和资料归属，再新增空 `sticker_assets` 与 `message_stickers` 表。旧配置、角色、会话、正文、图片、资料和凭据引用保持不变。个人备份升级为内容 v8/schema 13，包含素材与消息快照并继续读取 v1～v7；恢复前校验范围、名称、尺寸、MIME、哈希、数量和消息归属，追加恢复时重映射身份。
