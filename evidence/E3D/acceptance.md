# E3 第四项：受控生图服务开发记录

日期：2026-09-20。版本 0.16.0/code 16/schema 14。角色空间独立的受控生图服务已完成开发并形成签名交付；真实设备、SQLCipher/Keystore 落盘、图片解码与两个真实服务商尚未执行，因此状态为“E3 生图服务开发完成、验收待补齐”。E3 后续伴读与文件输出尚未完成，M1/M2/E1/E2 及 E3 前三项的原有待验项继续保留。

## 已接入

设置页新增独立的 OpenAI Images 兼容生图配置，保存服务地址、模型、尺寸、超时和凭据引用。API Key 继续由 Android Keystore 包裹保存并绑定服务地址；只允许 HTTPS，不跟随重定向，不复用聊天模型密钥，也不把密钥写入数据库、日志、备份或 APK。

聊天加号菜单新增“生成图片”。每次生成都明确填写提示词并预览目标角色、会话、服务地址、模型、尺寸和费用提醒；用户确认后才发送。请求冻结请求 ID、角色、空间、会话、提示词和配置快照。切换页面、修改角色或配置不会改变在途请求；取消、删除角色和备份恢复会停止相应任务，迟到结果不能写入错误会话。

服务只接受单张、有界的 `data[0].b64_json` 结果，拒绝 URL、文本、多图、超限 JSON、超限像素和无法解码的数据。成功图片重编码为静态 JPEG，最大边 1536、最多 2 MiB，按角色空间保存；每个会话最多 32 张生成图。失败明确保留错误类别，不下载远程结果，也不在失败时改用明文或其他接口。

Room 提供显式 13→14 迁移，迁移前检查角色、会话、消息、素材及资料归属，再新增空 `image_generation_configs` 与 `generated_images` 表。旧配置、角色、会话、正文、图片、资料、表情和凭据引用保持不变。个人备份升级为内容 v9/schema 14，并继续读取 v1～v8；恢复时校验范围和归属，未完成的导入记录转为失败或中断。
