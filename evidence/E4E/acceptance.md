## 已接入

每个角色空间可分别开启本机时间和已保存天气。时间在发送或重试时从系统时钟、当前时区和实际 UTC 偏移冻结，不为此联网。天气只使用用户手工获取且未超过六小时的完整快照；缺失、关闭、过期和原味模式都明确排除。角色、开关、地点或模型在生成期间变化不会改写在途请求。

天气固定使用 Open-Meteo。用户先检查完整城市文字、固定地点检索 HTTPS 地址和发送范围，确认后取得最多五个候选；再选择并检查城市、行政区、国家、时区、经纬度、固定天气地址和许可，第二次确认后才获取当前天气与三日预报。应用不请求定位权限、不读取设备位置、不按 IP 猜城市、不后台刷新、不携带 API Key、角色或聊天，不跟随重定向或自动重试。

地点、开关和最后快照保存在 SQLCipher 的角色独立记录。读取、开关、保存、清除、聊天上下文和删除均校验角色及空间。复制角色和公开模板不携带环境记录；个人备份 v15 保留并重映射，v14 及更早格式补入空环境表。
