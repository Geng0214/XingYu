## 待验与实际边界

`adb devices -l` 未列出连接设备。Android 官方播放器实际加载和解码、Cookie/DOM 存储关闭后的平台兼容性、全屏和旋转、停止/重开、来电/耳机/焦点、后台/锁定/角色切换、SQLCipher 落盘、WebView 旁路残留、0.30.0 覆盖安装和跨设备恢复均为 NOT_RUN。

官方访客播放器仅接收公开 BV/av 视频身份、分集和起播时间。应用没有提供聊天、人设、感想或 Key；未解析非公开媒体接口、绕过登录付费或复制媒体。只有用户预览确认的名称、链接、进度与感想可带回聊天草稿，不声称 AI 已读取视频内容。

WebView 禁用 Cookie、DOM/数据库存储、网页缓存、文件/content 访问、新窗口和网页权限，关闭时清历史/表单/缓存。系统 WebView 不提供可保证的全内存私密配置，这些开关不证明零残留；资源重定向的完整边界也仍待实机核对。发现观看身份旁路明文落盘时必须整改，不能以构建通过代替隐私验收。应用自己的记录使用原 SQLCipher 库。

未新增模块或运行依赖，沿用 API 36/AGP 8.13.2。评估中 GeckoView 155 要求 API 37，未进入产品，也未修改其元数据来规避要求。保留本机音乐、视频和现有扩展；ToolPkg 仍是纯计算兼容子集，并非全部 Operit 插件能力。
