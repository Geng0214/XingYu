# M2 开发与验收记录

范围：本地伴侣 0.2.0，Android 8.0+ / ARM64，Room schema 2。用户已确认保留 0.1.0 数据，允许先开发 M2，补齐 M1 验收后放行。

## 本机已验证

- JVM 24/24：原网络协议测试 13 项、协调器 5 项、模板 5 项、上下文 1 项。协调器含 20 轮角色切换、配置修改、取消、重试和删除等待组合；上下文含 50 次 A/B 交替及错误身份拒绝。
- 实际 DAO SQL 与迁移 SQL 在内存 SQLite 执行：50 次交替查询、越权读取/更新/删除拒绝、终态保护、中断恢复；升级结构与 Room v2 导出一致，原消息和凭据引用保留，孤立关联拒绝迁移。见 sql-host-check.json。此检查不代表 Android SQLCipher 或 Keystore 已验收。
- 模板测试覆盖中文/emoji、换行与引号、额外脚本/URL/身份/Key/路径字段丢弃、重复字段、非法 UTF-8、超限流、嵌套深度、格式版本和不完整代理字符。输出字段严格限制为版本、名称、人设、开场白。
- clean、JVM 测试、Debug/Release/设备测试 APK 和 Release Lint 构建通过：build-final-clean.log，2 分 28 秒，141 项任务。Release Lint 0 错误，40 警告和 1 提示。
- Lint 的 ExportedContentProvider 指向 Manifest 的 removeAll 标记；实际合并 Manifest 与 APK 没有 Provider。其余为工具链/依赖更新、版本目录、KAPT、KTX 和 ChromeOS ABI 提示。本轮不改动冻结工具链，不通过抑制规则掩盖检查。
- 签名校验确认与 0.1.0 相同的 SHA-256 证书指纹：ac7283d4cc843d710a77f3c5b3f96ee3663793b78e8fb30c6a145b8e37f497fa。包名保持，versionCode 从 1 增至 2。
- APK 静态扫描：仅启动 Activity，无服务/广播/Provider、无嵌入签名材料或测试 schema，保持原有权限与两份 16 KB 对齐原生库。最终哈希以 delivery.json 和 apk-audit.json 为准。
- 补充的迁移前后凭据读取测试已再次编译通过：build-device-tests.log。实现提交为 192850b9d38f4192fbc2d50efb17a8b3afc52278；clean 验证后重新执行签名打包，build-signed-commit.log 通过，APK 内嵌 revision 与源码包提交一致。最终 APK 为 6807672 字节，SHA-256 为 406aaf2dd4120778277690cb35aea534630214bb13405837db4e063941b96f43。

- Debug/Release KAPT 并发写同一份 Room schema 导致 JSON 读到 EOF；已以 mustRunAfter 固定写入顺序，后续完整 clean 构建通过。
- 新增角色作用域参数曾遮蔽协调器 CoroutineScope；已明确区分命名并通过编译和协调器测试。
